# OPAQUE ID Authentication System

## Overview
A secure authentication system implementing the OPAQUE password-authenticated key exchange protocol.

## Features
- User Registration
- User Login
- Password Hashing
- MongoDB Database
- FastAPI Backend
- React Frontend

## Tech Stack
- React
- FastAPI
- MongoDB Atlas
- MongoDB Compass
- Python
- JavaScript

## Folder Structure
backend/
frontend/

## Installation

### Backend
cd backend
pip install -r requirements.txt
uvicorn app:app --reload

### Frontend
cd frontend
npm install
npm run dev
